# Saiful Islam Rumman — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and active-section highlighting
- `assets/profile.jpg` — add your own professional photo
- `assets/resume.pdf` — add your latest PDF CV

## Before publishing
1. Replace `your.email@example.com` with your real email address.
2. Add your photo as `assets/profile.jpg`.
3. Add your CV PDF as `assets/resume.pdf`.
4. Verify education, job titles, dates and all descriptions.
5. Replace the project placeholders with real projects when ready.
6. Remove any skill you cannot yet confidently demonstrate.

## Publish with GitHub Pages
1. Create a public repository named `mdsaifulislamrumman.github.io`.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment. Your site will be available at:
   `https://mdsaifulislamrumman.github.io`

## Note
The site uses Google Fonts from Google Fonts. If external fonts are unavailable, it falls back to system sans-serif fonts.
